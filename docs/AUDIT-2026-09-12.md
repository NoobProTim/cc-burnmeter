# Environment-assumption audit — 2026-09-12 (pre-release)

Read-only audit of `meter.cjs`, `proxy.cjs`, `statusline.cjs`, `meter.html` at commit b9972ba. Line numbers
are from that commit. Each row: where, the assumption, what breaks for a different user. The P0 list in
`PUBLISH-PLAN.md` §2 is the fix list for this table.

| # | File:line | Assumption | What breaks |
|---|---|---|---|
| 1 | meter.cjs:78-81 | `stripSlugPrefix` strips the literal `/^-Users-tj-/` | Every other user sees full, ugly project slugs. Derive from `os.homedir()`. |
| 2 | meter.cjs:19-22, proxy.cjs:29-30, statusline.cjs:20 | Paths from `os.homedir()` only | Ignores `CLAUDE_CONFIG_DIR` (and `CLAUDE_CODE_PROJECT_DIR_NAME`): silently empty dashboard. |
| 3 | meter.cjs:843, 850-852 | `fs.watch(..., {recursive:true})`, silent catch | Linux: throws or no-ops; user gets 10 s lag with no notice. |
| 4 | meter.cjs:44-58, 72 | Price table keyed by first-party model-name substrings | Bedrock ARNs / Vertex paths / future ids → `costUSD: null`, shown as `?`. Normalize ids, read settings `modelPricing`, show "unpriced (N calls)". |
| 5 | meter.cjs:59, 66-69 | `FAST_OPUS_KEYS` hardcoded | New fast-tier model needs a code change. |
| 6 | meter.cjs:1044, proxy.cjs:371 | No `error` handler on `listen` | EADDRINUSE crashed the process. **Fixed in b9972ba** (both servers). |
| 7 | meter.cjs:387-391 | `discoverFiles` swallows `readdirSync` errors → `[]` | Missing dir, permissions, or zero sessions all look like an empty dashboard. Needs `--doctor`. |
| 8 | meter.cjs:797 | `Promise.all` over every transcript at startup | Thousands of files → `EMFILE` at a 256 fd limit. Cap concurrency (32). |
| 9 | meter.cjs:444-476 | `sessionsMap` never evicts | Unbounded memory in a days-long server. Evict outside `--hours`. |
| 10 | meter.cjs:349-373 | Subagent layout `<session>/subagents/agent-<id>.jsonl` + `.meta.json` | A layout change silently drops subagent rows. Tolerate + report in `--doctor`. |
| 11 | meter.cjs (none) | No handling of `--no-session-persistence` / `CLAUDE_CODE_SKIP_PROMPT_HISTORY` | Invisible sessions with no explanation. `--doctor` line. |
| 12 | meter.cjs:996-1039 | `/api/state`, `/api/session/:id`, `/events` unauthenticated, no Host/Origin check | Containers, forwarded ports, DNS rebinding read everything. Bearer token + loopback Host check. |
| 13 | meter.cjs:302-311, 574; meter.html:574 | First 140 chars of every prompt served over that API | Real prompt content leaks. Off by default (`--show-prompts`). |
| 14 | proxy.cjs:31 | `PROXY_UPSTREAM` defaults to api.anthropic.com | A pre-existing corporate `ANTHROPIC_BASE_URL` is silently bypassed. Capture it at wire time. |
| 15 | proxy.cjs:267-269 | Core `https.request`, no forward-proxy support | `HTTPS_PROXY`/`NO_PROXY` ignored; corporate networks unreachable. |
| 16 | proxy.cjs (all) | No client-cert path | mTLS gateways unreachable. Honor `CLAUDE_CODE_CLIENT_CERT/KEY/PASSPHRASE`. `NODE_EXTRA_CA_CERTS` already works. |
| 17 | proxy.cjs (architecture) | Single Anthropic-shaped `ANTHROPIC_BASE_URL` | Bedrock/Vertex/Foundry never route through it. Document: transcript tier only. |
| 18 | proxy.cjs:40-49, 263-264 | Pass-through of every non-hop-by-hop header incl. auth | Correct and intended; `apiKeyHelper` works for free. |
| 19 | proxy.cjs:266 | `new URL(req.url, upstream)` unguarded | A malformed URL throws inside the request callback. **Mitigated in b9972ba** by `uncaughtException` logging; still wrap it and answer 400. |
| 20 | proxy.cjs:134-146 | `rotateIfNeeded` only at startup; one backup slot | `live.jsonl` grows unbounded in a long-lived service. Rotate while running. |
| 21 | statusline.cjs:11 | Setup comment uses `~` in the command | Native Windows does not expand it. Write absolute paths at wire time. |
| 22 | statusline.cjs:84-96 | First-seen session starts at the current offset | "session: X in" understates until restart. Bounded backfill or a "since HH:MM" label. |
| 23 | statusline.cjs:163-198 | Every error → `token-meter: n/a`, exit 0 | Misconfigurations invisible. Rotating log. |
| 24 | meter.html:94, 98, 114 | CSS `color-mix()` | Older engines lose hover/in-flight tints. Fallback color first. |
| 25 | meter.html (all) | No external loads; relative fetches only | Good. Keep it that way. |
| 26 | all three | No modern-syntax dependencies; Brotli needs Node ≥ 11.7 | Node 18 floor is safe. |
| 27 | meter.cjs, proxy.cjs | No `uncaughtException`/`unhandledRejection` handlers | **Fixed in b9972ba for the proxy** (log and keep serving). Dashboard still exits on listen error by design. |

Top ten for a public release, in order: 12+13 (prompt text over an open API), 27 (proxy death = Claude Code
outage), the proxy's lack of real-traffic testing beyond one machine, 15, 16+17, 14, 6, 2, 4, 3+1.
